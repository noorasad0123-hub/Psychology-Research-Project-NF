Study Habits and Student Well-being

Purpose

This fictional class project explores how students' study habits may relate to their well-being. It aims to understand the importance of sleep, time management, breaks, and study routines in students' daily lives.

Files

- "project_plan.docx" — Project objectives and planning.
- "survey_draft.docx" — Draft questions for a fictional class survey.
- "data_dictionary.xlsx" — Description of the variables planned for the project.
